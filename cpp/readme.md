# C++

Practice and small projects in C++, organized into two folders:

## `dsa/`
Data structures and algorithms practice — solutions built to develop fluency with core concepts (arrays, linked lists, trees, sorting, searching, recursion, etc.). Not full projects — standalone solutions, one file per problem, named by what they solve (e.g. `reverse-linked-list.cpp`, `binary-search.cpp`).

## `projects/`
Small, self-contained C++ programs — complete enough to compile and run, demonstrating a specific concept or set of concepts (classes, control flow, file/data handling, basic I/O). Each project has its own subfolder with a short README describing what it does and how to run it.

Current projects:
- **Library Management System** — group project (team of 3); console-based menu-driven app for managing a book collection (add, view, search, sort). Built to practice OOP and combine core C++ concepts.
- **Guess the Number** — number-guessing game demonstrating loops, conditionals, and randomization.
- **Nested Functions Exercises** — programming-fundamentals practice covering function structure and control flow.
