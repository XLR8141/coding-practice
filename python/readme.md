# Python

Beginner-level Python practice, plus one small project.

## Files

- **calculator.py** — basic calculator (arithmetic operations via console input)
- **numpy_calculator.py** — calculator rebuilt using NumPy, for practicing array/numeric operations
- **course-recommendation-system.py** — simple beginner-level recommendation logic for suggesting courses
- **chatbot.py** — basic chatbot using prebuilt/hardcoded questions and responses

## `interview-chatbot/`
A small Tkinter-based mock interview chatbot — see its own README for details.
