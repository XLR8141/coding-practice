# Machine Learning

Practice notebooks covering the core machine learning workflow: wrangling and exploring data, preprocessing it, understanding and applying common algorithms, and putting it all together on beginner datasets. These are learning notebooks, not production projects.

## Structure

### `concepts/`
Notes and experiments on ideas that explain why ML techniques behave the way they do.
- Curse of dimensionality

### `algorithms/`
Practice with core ML algorithms.
- Regression
- Gradient descent
- Naive Bayes
- K-Nearest Neighbors (KNN)
- Decision trees
- Ensemble learning

### `data-preprocessing/`
Preparing data for modeling.
- Data cleaning
- Filling missing values
- Handling outliers
- Standardisation and normalisation
- Function transformer and power transformer
- Nominal and ordinal encoding
- Converting numerical features to categorical
- Pipelines and column transformers

### `data-wrangling/`
Manipulating and loading data with pandas.
- Groupby
- Merge, join and apply
- Working with files and file handling
- Working with dates and time

### `eda/`
Exploratory data analysis.
- Univariate analysis
- Bivariate and multivariate analysis
- Pandas profiling

### `notebooks/`
End-to-end practice on beginner datasets, combining EDA, preprocessing, model training and evaluation.
- Titanic survival prediction
- Melbourne house price prediction
- Placement prediction

## Notes
- Each notebook starts with a short markdown cell describing what it practices.
- Larger standalone projects are kept in their own repositories, not in this folder.
